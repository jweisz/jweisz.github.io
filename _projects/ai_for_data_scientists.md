Automated machine learning (AutoML) promised to automate much of a data scientist's work, from preparing data to selecting and tuning models. We asked what that automation means for the people doing the work, and how to design AutoML systems that keep humans in the loop.

## How data scientists see automated AI

We interviewed data scientists about their perceptions of automated AI and how they expected it to change their work. We also studied the information data scientists need before they will trust an AutoML system.

## Human-in-the-loop AutoML

These findings shaped tools for IBM AutoAI, which automates the end-to-end AI lifecycle while keeping humans in the loop. AutoAIViz opens the black box of automated AI by visualizing the pipelines it generates with conditional parallel coordinates. Model LineUpper supports interactive comparison of the models that AutoML produces, at multiple levels of detail. AutoDS explores human-centered automation of the broader data science workflow.

## Documenting data science code

Data scientists often skip documenting their code in computational notebooks. We built an AI system that generates documentation for notebook code, and we studied how data scientists improve the documentation it produces.
