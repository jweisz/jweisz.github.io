CardKit is a programming framework for developing IoT applications using a **card-based metaphor**. Instead of writing code, users program devices such as drones by arranging cards that represent actions, inputs, and AI services {% cite abs-1804-08458 %}. This low-code paradigm makes programming IoT applications easy and fun!
