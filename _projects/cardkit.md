CardKit is a programming framework for IoT applications built around a **card-based methodology**. Instead of writing code, users program devices such as drones by arranging cards that represent actions, inputs, and AI services. This puts programming within reach of business users and other domain experts.

The [CardKit GitHub organization](https://github.com/CardKit/) has the core framework, a runtime, card libraries for drones (including DJI drones) and Watson AI services, and a sample drone app.
